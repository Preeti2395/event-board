 # Campus Event Board

Campus Event Board is a responsive website developed for the Web Programming Lab at IIIT Vadodara. It provides information about campus events, student clubs, schedules and other campus activities.

## Features

- Upcoming campus events
- Event submission form
- Event schedule
- Student clubs section
- Campus gallery
- FAQ section
- Responsive navigation
- Mobile-first responsive design
- Responsive images and typography
- Keyboard-accessible navigation

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries

## Responsive Design

The website follows a mobile-first approach.

Different layouts are provided for:
- Mobile devices
- Tablets
- Desktop screens

CSS media queries are used to adjust the layout according to the screen width.
